# Sonic-SFML — Sonic.EXE: Last Protocol

A 2D Sonic-inspired game built with **C++ and SFML**, featuring dark themes, corrupted characters, combat systems, and custom game mechanics.

## 🎮 About the Project

Sonic-SFML is a C++ game project inspired by the darker side of the Sonic universe. It uses SFML for graphics, input handling, and game development, with a modular codebase designed to organize gameplay systems.

## ✨ Features

- **C++ and SFML** game development.
- Modular architecture with separate source and header files.
- Character and enemy systems.
- Combat and damage handling.
- Particle effects and explosions.
- Camera and game-state management.
- Sprite animation and texture management.
- Dark Sonic-inspired atmosphere.

## 🛠️ Built With

- **C++**
- **SFML**
- **CMake**
- **Ninja** (build system)

## 📁 Project Structure

```text
Sonic-SFML/
├── assets/       # Textures, fonts, and sprite data
├── extras/       # Additional demo code
├── include/      # Header files
├── src/          # Main source code
├── tools/        # Development utilities
├── CMakeLists.txt
└── .gitignore
```

## ⚙️ Building the Project

### Requirements

- A C++ compiler
- CMake
- SFML and its required dependencies
- Ninja, if using the Ninja generator

### Build Instructions

From the project root, run:

```bash
cmake -S . -B build -G Ninja
cmake --build build
```

**Note:** Make sure the SFML dependency is installed and configured correctly for your compiler and environment before building.
